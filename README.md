# Goviz: Interactive Algorithm Visualizer

AlgoVis adalah platform edukasi interaktif yang dirancang untuk memvisualisasikan cara kerja berbagai algoritma Sorting dan Searching. Proyek ini bertujuan membantu mahasiswa dan pengembang memahami kompleksitas dan alur eksekusi algoritma secara real-time.

## 🚀 Fitur Utama
*   **Visualisasi Langkah-demi-Langkah**: Lihat setiap operasi (pertukaran, perbandingan, pointer) secara visual.
*   **Mode Belajar (Learning Mode)**: Penjelasan tekstual untuk setiap langkah algoritma yang sedang berjalan.
*   **Input Data Kustom**: Masukkan dataset angka kamu sendiri untuk melihat bagaimana algoritma bereaksi terhadap kasus tertentu.
*   **Kontrol Kecepatan & Navigasi**: Kendalikan simulasi dengan fitur Play, Pause, Step-by-Step, dan Reset.
*   **Analisis Kompleksitas**: Informasi mengenai Time Complexity (Best, Average, Worst) dan Space Complexity yang transparan.

## 🛠️ Stack Teknologi
*   **Framework**: Next.js 14+ (App Router)
*   **Bahasa**: TypeScript
*   **Styling**: Tailwind CSS
*   **State Management**: Zustand
*   **Logika**: Algoritma yang diimplementasikan menggunakan generator functions untuk kontrol langkah yang presisi.

## 📈 Roadmap Implementasi

### Phase 1 (MVP - Done)
*   **Searching**: Linear Search, Binary Search.
*   **Sorting**: Bubble, Selection, Insertion, Merge, Quick Sort.

### Phase 2 (In-Progress)
*   **Searching**: Jump, Interpolation, Exponential, Fibonacci Search.
*   **Sorting**: Heap, Shell, Counting, Radix, Bucket Sort.

### Phase 3 & 4 (Upcoming)
*   Implementasi Graph Search (BFS/DFS/A*), String Search (KMP/Rabin-Karp), dan algoritma unik lainnya (Bogo Sort, TimSort, dll).

## 💻 Cara Menjalankan Proyek
1. Clone repositori ini.
2. Jalankan `npm install` untuk menginstal dependencies.
3. Jalankan `npm run dev` untuk memulai development server.
4. Buka `http://localhost:3000` di browser kamu.
